Understanding Reference Points & Frames

1. Reference Point (Origin $x_0$): Motion is relative! To describe the position of an object, we must choose a fixed point called the Reference Point.

2. Total Distance ($D$): The total length of the path traveled by the car. Distance is a scalar quantity, always positive or zero ($D \ge 0$), and does NOT change when you move the reference flag!

3. Displacement ($\Delta x$): The shortest vector distance from the reference point to the object ($\Delta x = x_{\text{car}} - x_{\text{ref}}$). It has magnitude and direction ($+$ or $-$).
